# Sample Documents for AI Knowledge Assistant

This folder contains sample text files that you can use to test the AI Knowledge Assistant. Each file covers a different topic. The assistant will chunk, embed, and index these documents to answer questions.

## Files
- `python_basics.txt` – Introduction to Python programming basics.
- `solar_system.txt` – Facts about our solar system.
- `machine_learning.txt` – Overview of machine learning concepts.

You can add your own `.txt` files to this directory to expand the knowledge base.
